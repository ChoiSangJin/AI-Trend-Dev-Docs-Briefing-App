## AI 모닝 브리핑 v1.0.4

기존 앱이 `gemini-2.5-flash-lite`를 우선 선택해 생성 요청에서 `HTTP 404 NOT_FOUND`가 발생한 문제를 수정합니다. Google 공식 문서는 2.5 계열의 접근을 과거 사용 이력이 있는 사용자 중심으로 제한하고 새 프로젝트에는 최신 모델을 권장합니다. 모델 목록에 표시되는 것만으로 해당 프로젝트의 생성 접근을 보장할 수 없었습니다.

- 목록에 있는 Gemini 3 이상 안정 버전 Flash-Lite 중 최신 버전을 우선하고, 안정 버전 Flash와 최신 별칭을 후순위로 선택합니다. 2.5 계열은 자동 선택하지 않습니다.
- 기존 설치의 2.5 모델 설정도 업데이트 후 첫 요약에서 저장된 키로 자동 갱신합니다.
- 생성 요청이 404일 때만 실패 모델을 기기에 기록해 제외하고 목록을 갱신한 뒤 다른 모델로 한 번 전환합니다. 실패 모델이 목록에 계속 있어도 재선택하지 않습니다.
- 두 번째 404 이후에는 중단합니다. 400·401·403·429·5xx·시간 초과는 자동 재시도하지 않습니다. 실패 기록과 할당량 제한은 재시작 후에도 유지하며, 키를 직접 다시 등록하면 이전 프로젝트의 실패 모델을 초기화합니다.

Android 7.0 이상 arm64용입니다. 버전 코드는 5이며 기존 v1.0.3과 서명이 같아 업데이트 설치할 수 있습니다.

검증: 분석·포맷·테스트 77개, arm64 release 빌드, APK 서명·버전·16KB ZIP 정렬·체크섬. 테스트는 기존 2.5 설정 갱신, 최신 모델 선택, 404 모델 제외 및 대체 성공, 두 번 실패 후 중단, 다른 오류에서 추가 요청 금지, 재시작·동시 요청·새 키 등록을 포함합니다. 사용자의 실제 Google 키·기기에서 생성 성공은 아직 확인하지 않았습니다.

공식 근거: [2.5 접근 제한 안내](https://ai.google.dev/gemini-api/docs/deprecations#gemini-2.5-flash-models), [Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite), [가격·Free Tier](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite). 계정별 권한·지역·할당량은 Google 정책에 따릅니다.
