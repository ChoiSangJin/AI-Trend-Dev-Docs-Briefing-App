## AI 모닝 브리핑 v1.0.10

- Gemini 503 응답에서 Retry-After(초 또는 HTTP 날짜)를 처리하고, 없거나 잘못된 경우 기본 5초 후 다른 제공 모델로 한 번 전환합니다. 대기는 최소 1초~최대 24시간으로 제한합니다.
- 자동 대기가 30초를 넘으면 생성 요청을 추가하지 않고, 대기 시각을 저장해 앱 재시작 후 수동 요청에도 적용합니다.
- 다른 모델이 없으면 같은 모델을 재요청하지 않습니다. 404·503이 섞여도 한 작업의 생성 요청은 최대 두 번입니다. 503 모델은 영구 제외하지 않습니다.
- 인증·권한·할당량·500·시간 초과 오류는 자동 전환하지 않습니다. 5xx 오류에는 실제 요청 모델을 표시하고, 원문 오류 본문과 키는 표시하지 않습니다. 로딩 안내도 모델 전환 가능성을 반영합니다.

검증: 분석·테스트 110개, 503 대체 성공·대기·연속/혼합 실패 상한·긴 Retry-After·HTTP 날짜·재시작 후 대기·대체 모델 없음·기존 인증/할당량 동작. arm64 release APK·기존 서명 일치·체크섬·16KB ZIP 정렬.

사용자의 실제 Google 키로 생성 성공을 확인하지는 않았으며, Google 전체 장애나 모든 제공 모델의 이용 불가를 해결하는 기능은 아닙니다.

버전 1.0.10+11, Android 7.0 이상 arm64용입니다.
