## AI 모닝 브리핑 v1.0.2

기존 버전은 특정 모델의 생성 호출로 API 키를 확인하고 404·5xx를 같은 임시 장애 문구로 표시했습니다. 따라서 모델 문제와 서버 장애가 키 인증 실패처럼 보일 수 있었습니다.

- 키 확인을 Google 모델 목록 조회로 분리합니다. 키 확인만으로 콘텐츠를 생성하지 않으며, 확인 직후 첫 요약 요청이 가능합니다.
- 목록에 실제로 있는 텍스트 Flash 모델을 선택합니다. 사용 가능한 경우 `gemini-flash-latest`를 우선하며, 특정 2.5 모델용 요청 옵션을 최신 별칭에 강제하지 않습니다.
- 잘못된 키, 프로젝트·앱 제한, 모델 없음, 할당량, 서버 오류, 연결·시간 초과를 구분하고 HTTP 코드와 안전한 상태·사유 코드를 안내합니다.
- 원문 오류 메시지와 키 값은 표시하지 않으며, 서버 응답을 받지 못한 경우 HTTP 코드를 임의로 표시하지 않습니다.

Android 7.0 이상 arm64용이며 기존과 같은 서명 키를 사용합니다. 버전 코드는 3입니다. 분석·테스트 48개·PR CI·APK 서명·arm64 구성·버전·16KB ZIP 정렬을 검증했습니다.

사용자의 실제 Google 키나 기기에서 받은 실패 응답은 확인하지 않았습니다. 키 확인 성공이 요약 생성의 프로젝트 권한·지역·할당량까지 보장하지는 않습니다. 업데이트 후에도 실패하면 화면의 HTTP 코드·상태 코드만 확인하세요. API 키 값은 공유하지 마세요.
