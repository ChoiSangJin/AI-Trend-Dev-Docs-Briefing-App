## AI 모닝 브리핑 1.0.0

해외 AI 소식과 개발 문서를 한국어 세 줄로 읽는 Android 앱입니다.

- 3단계 무료 AI 열쇠 등록 안내 및 기기 보안 저장
- RSS/Atom 소스 10개, 소스 선택·추가, Daily Papers 실패 시 arXiv 대체
- Gemini 배치 요약, 쉬운 기술 용어 풀이, 로컬 캐시·읽음 기록
- 연속 학습 기록과 시간대별 일일 알림

### 설치

`ai-morning-briefing-arm64.apk`를 내려받아 **Android 7.0 이상 arm64 기기**에 설치하세요. Android에서 해당 브라우저/파일 앱의 APK 설치를 허용해야 할 수 있습니다. 첫 실행 시 본인의 Google AI Studio 열쇠를 등록합니다. 구글의 지역·계정별 이용 조건과 무료 한도가 적용됩니다. 별도 백엔드·로그인·광고는 없습니다.

`SHA256SUMS.txt`로 다운로드 파일을 검증할 수 있습니다. APK는 배포용 개인 키로 서명했으며 arm64 외 네이티브 라이브러리를 포함하지 않습니다.

### 확인된 검증과 범위

정적 분석, 단위·위젯 테스트 24개, 실제 SDK Atom 피드 파싱, debug·release APK 빌드, APK 서명·arm64 구성·16KB ZIP 정렬 검증을 통과했습니다. 실제 사용자 Gemini 열쇠 및 실기기의 알림 권한·재부팅·브라우저 복귀 동작은 아직 확인하지 않았습니다.

AI 요약은 피드 발췌문에 근거하며 틀릴 수 있습니다. 중요한 내용은 원문에서 확인하세요. 열쇠 확인 직후에는 공통 호출 제한에 따라 65초 후 요약을 다시 시도하세요. 알림은 앱 설정에서 직접 켭니다.
