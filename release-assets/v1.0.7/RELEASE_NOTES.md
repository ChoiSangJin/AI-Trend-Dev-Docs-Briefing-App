## AI 모닝 브리핑 v1.0.7

- Ahead of AI 기본 소스의 최대 피드 크기를 2MB에서 8MB로 늘립니다. 나머지 소스·사용자 피드는 2MB 제한을 유지하고, 기사 발췌문도 기존 길이로 제한합니다.
- HTTP 429를 받으면 Retry-After(초 또는 HTTP 날짜)를 따릅니다. 없으면 5분 대기하며, 대기는 최소 1분~최대 24시간입니다. 앱 실행 중 같은 URL을 반복 새로고침해도 대기 동안 요청을 보내지 않습니다. 자동 재시도하지 않으며, 앱 재시작 후 대기 정보는 유지하지 않습니다.

남은 제한: 실제 Ahead of AI 피드의 전체 크기와 수집 성공, LlamaIndex Blog 주소와 LangChain 응답은 개발환경 접근 정책으로 검증하지 못했습니다. 8MB도 넘는 피드는 계속 차단됩니다. VentureBeat의 서버 요청 제한 자체를 해제하는 수정은 아닙니다.

검증: 분석·테스트 87개, 3MB 정상 RSS와 발췌문 제한, 8MB 초과 차단, 기존 2MB 제한, Retry-After·반복 요청 억제·대기 후 수동 요청. arm64 release APK와 기존 서명 일치, 체크섬·16KB ZIP 정렬을 검증합니다.

버전 1.0.7+8, Android 7.0 이상 arm64용입니다.
