## AI 모닝 브리핑 v1.0.1

- API 키의 접두사와 길이를 강제하던 검사를 제거했습니다.
- 온보딩 안내를 **“API 키를 복사해서 가져오세요”**로 바꿨습니다.
- 입력 앞뒤 공백을 제거하고 빈 값만 안내하며, 실제 Google 응답으로 키를 확인한 뒤 암호화 저장합니다.
- 붙여넣기·입력 힌트·설정·오류 안내를 API 키라는 표현으로 통일했습니다.

Android 7.0 이상 arm64 기기용입니다. 기존 v1.0.0과 같은 서명 키를 사용하고 버전 코드를 2로 올려 업데이트 APK로 배포합니다.

정적 분석, 테스트 27개, PR CI, arm64 release APK 구성·서명·버전·16KB ZIP 정렬 검증을 통과했습니다. 실제 사용자 API 키를 사용하는 호출과 Android 실기기 설치는 실행하지 않았습니다. 다운로드 파일은 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.
