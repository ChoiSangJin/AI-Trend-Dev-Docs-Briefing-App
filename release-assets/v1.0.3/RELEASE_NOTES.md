## AI 모닝 브리핑 v1.0.3

- GeekNews 등 게시 빈도가 높은 소스가 10개 자리를 모두 차지하지 않도록, 출처별 최신 기사를 하나씩 고른 뒤 남은 자리를 채웁니다. 화면에 선택된 출처 수도 표시합니다.
- RSS의 `+0900`·`+0000` 같은 숫자 시간대를 읽어 날짜 정렬에 반영합니다. 피드 수집 실패 시 HTTP·연결·형식 안내를 구분합니다.
- Google에서 제공되는 모델 목록을 확인한 뒤 짧은 요약에 맞는 Flash-Lite 모델을 우선 선택합니다. 기존 설치도 업데이트 후 첫 요약에서 모델 선택을 갱신합니다.
- 기사별 입력과 출력 지침을 줄이고, 요약 응답 본문까지 최대 120초를 기다립니다. 제한 시간 초과 시 실제 전송을 취소하며 자동으로 생성 요청을 재시도하지 않습니다.

Android 7.0 이상 arm64용입니다. 버전 코드는 4이고 기존 v1.0.2와 서명이 같아 업데이트 설치할 수 있습니다.

검증: 분석·포맷·테스트 62개, 실제 OpenAI·Anthropic SDK Atom 수집, arm64 release 빌드, APK 서명·버전·16KB ZIP 정렬·체크섬. 테스트에는 한 소스의 기사 편중, 숫자 시간대 정렬, 기존 모델 선택 갱신, 61초 뒤 응답 완료, 헤더·본문 대기 중 전송 취소를 포함합니다.

사용자의 실제 Google 키·기기에서 요약 생성이 성공하는지는 확인하지 않았습니다. 스크린샷은 시간 초과를 보여주지만 Google 서버 지연과 사용자 통신 문제 중 어느 원인인지 확정하지 못했습니다. 전체 외부 피드의 실시간 점검은 클라우드 접근 정책으로 제한됐습니다. 계속 실패하면 API 키 대신 화면의 오류 안내만 확인해 주세요.
